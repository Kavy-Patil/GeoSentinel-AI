# GeoSentinel AI - Data Directory

This directory is designated for local storage of sample and benchmark satellite datasets in future stages:

- `samples/`: Curated pairs of before/after GeoTIFF imagery (e.g., Urban Encroachment, Flood, Deforestation).
- `benchmarks/`: Validation datasets with ground truth change masks.
- `temp/`: Intermediate preprocessing rasters (excluded from version control).

> **Stage 1 Note:** No datasets or ML weights are downloaded or stored in Stage 1.
